## 🔬 About the Project

The **Periodic Table Web Application** is an educational web application that provides an interactive way to explore the chemical elements.

Users can view the complete periodic table, search for elements, and access detailed information about individual elements.

The application is designed for:

- Students
- Teachers
- Chemistry enthusiasts
- Developers
- Anyone interested in learning chemistry

The main purpose of this project is to make learning about chemical elements more interactive, simple, and accessible.

---

## ✨ Features

### 🧪 Interactive Periodic Table

- Displays chemical elements in the standard periodic table layout.
- Elements are organized according to atomic number.
- Elements are grouped according to their chemical properties.
- Each element can be selected to view additional information.

### 🔎 Element Search

Users can search for elements using:

- Element name
- Chemical symbol
- Atomic number

Examples:

```text
Hydrogen
H
1
```

```
The application can provide the following information for each element:

Symbol	Short chemical representation

Atomic Mass	Average atomic mass
Group	Periodic table group
Period	Periodic table period
Category	Chemical classification
Electron Configuration	Arrangement of electrons
Physical State	Solid, liquid, or gas
Density	Mass per unit volume
Melting Point	Temperature at which the element melts
Boiling Point	Temperature at which the element boils
Electronegativity	Ability to attract electrons in a chemical bond
```
